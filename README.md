# SLV Infra Tech website

Residential construction in South Bengaluru — static website (HTML, CSS, JavaScript). No build step.

- Live site: https://pavan-krishna28.github.io/SLVInfraTech/
- Edit rates and settings at the top of `site.js` (`CONFIG`).
- Package specifications are in `packages-data.js`.
- Enquiries open WhatsApp by default; set `CONFIG.leadEndpoint` in `site.js` to send them to a form backend instead.

Hosted with GitHub Pages from the `main` branch (root folder).
